# MedScript 🩺

MedScript is an intelligent, patient-centric Visit Assistant web application designed to help individuals better prepare for, record, and summarize their doctor appointments. Built with modern web technologies, MedScript leverages AI to transcribe medical conversations and provide clear, actionable summaries and insights.

## ✨ Features

- **🧑‍⚕️ Visit Prep:** Easily compile your symptoms, questions, existing conditions, and current medications before your doctor visit.
- **🎙️ Audio Recording:** Securely record your doctor's visit directly within the application.
- **🤖 AI Transcription & Summarization:** Automatically transcribe the recorded visit and generate a clear, concise summary using advanced AI models. Extracts key points, recommendations, and next steps in plain language.
- **👨‍👩‍👧‍👦 Patient Profiles:** Manage visits for yourself and your family members all in one place.
- **📊 Medical Insights:** Keep track of your medical history and upcoming tasks.

## 🚀 Technology Stack

- **Frontend Framework:** React 18 with Vite
- **Routing:** React Router DOM
- **Styling:** Tailwind CSS & Framer Motion for animations
- **UI Components:** Radix UI & Shadcn UI (accessible, unstyled components)
- **State Management:** TanStack React Query
- **Data & AI Integration:** Base44 SDK

## 📦 Installation

To get a local copy up and running, follow these simple steps:

1. **Clone the repo**
   ```sh
   git clone https://github.com/ShreyeshReddy005/MEDSCRIPT.git
   ```
2. **Install NPM packages**
   ```sh
   npm install
   ```
3. **Run the development server**
   ```sh
   npm run dev
   ```

## 🏗️ Project Structure

- `/src/components`: Reusable UI components (buttons, dialogs, form inputs, etc.)
- `/src/pages`: Main application views (Visit Assistant, Insights, etc.)
- `/src/lib`: Utility functions and context providers (Authentication, Query Client)
- `/src/api` & `/src/entities`: Data models and API integration logic
